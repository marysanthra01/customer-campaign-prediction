# customer-campaign-prediction
Machine learning project predicting customer responses to marketing campaigns using Python and Scikit-learn.
## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab
## Data Preparation
The project includes:
- Missing-value handling
- Outlier treatment using the IQR method
- Encoding of categorical variables
- Standardisation of numerical features
- Feature selection using SelectKBest
- Train, validation, and test data splitting

  ## Machine Learning Models
Three classification models were developed and compared:

- Logistic Regression
- Decision Tree
- Neural Network (MLP Classifier)
## Model Evaluation
The models were evaluated using:
- Accuracy
- Confusion Matrix
- Classification Report
- Precision
- Recall
- F1-score

The model with the highest validation accuracy was selected and evaluated on unseen test data.
## Outcome
The project demonstrates how machine learning can be used to predict customer responses to marketing campaigns. The analysis provides a framework for identifying customers who are more likely to take a new contract, which could support more targeted marketing decisions.
